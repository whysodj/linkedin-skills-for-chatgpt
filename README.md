# LinkedIn Skills for ChatGPT

**A modular LinkedIn content and growth skill system for ChatGPT.**

**Author:** DJ  
**Repository:** `whysodj/linkedin-skills-for-chatgpt`

---

## 🚀 What is this?

**LinkedIn Skills for ChatGPT** is a modular system for turning ChatGPT into a focused LinkedIn content and growth assistant.

Instead of relying on one giant prompt, the system separates LinkedIn work into specialized skills. Each skill has one clear job, and the router can combine them into a larger workflow when needed.

The goal is simple:

> **Plan better. Write better. Sound human. Engage intentionally. Grow a stronger LinkedIn presence.**

---

## 🧠 How It Works

The system follows a modular workflow:

```text
                    LINKEDIN SKILLS FOR CHATGPT
                               │
                         ┌─────┴─────┐
                         │   ROUTER   │
                         └─────┬─────┘
                               │
       ┌───────────────┬───────┼────────┬───────────────┐
       ↓               ↓       ↓        ↓               ↓
    CONTENT          WRITING  AUDIT   PROFILE       ENGAGEMENT
       │               │       │        │               │
       ↓               ↓       ↓        ↓               ↓
    Planning         Posts   Humanize  Optimize      Comments
    Repurposing      Hooks   Review    Positioning   Replies
                                               Thread Monitoring
```

For a typical post:

```text
Idea
 ↓
Hook
 ↓
Draft
 ↓
Audit
 ↓
Humanize
 ↓
Publish
 ↓
Engage
 ↓
Review
```

For more complex work, multiple skills can be chained together automatically.

## 🎯 Design Principles

### 1. Authenticity over AI polish

The system should improve writing without making every post sound like it was generated by the same AI.

### 2. Specificity over generic advice

Concrete experiences, observations, examples and lessons are preferred over vague motivational content.

### 3. Conversations over vanity metrics

Reach can be useful, but the system prioritizes meaningful engagement, relevant profile views, conversations and qualified opportunities.

### 4. Originality over copying

Successful posts can be analyzed for structure and patterns, but wording and ideas should be adapted into original content.

### 5. Facts over fabrication

The system must never invent personal experiences, achievements, metrics, clients, testimonials or credentials.

### 6. Modular skills over one giant prompt

Each skill has a focused responsibility. This makes the system easier to understand, improve, replace and extend.

## 🛠️ Using the System

The files in this repository are designed as reusable skill instructions for ChatGPT-compatible skill workflows and other agentic AI environments that support modular skill files.

You can:

- Use individual skills independently.
- Combine several skills into a workflow.
- Customize the rules for your own voice and audience.
- Add new LinkedIn-specific skills.
- Adapt the router to your preferred workflow.
- Fork the repository and build your own version.

For personal use, update `USER-CONTEXT.md` with information you intentionally want the system to use for LinkedIn positioning and writing.
