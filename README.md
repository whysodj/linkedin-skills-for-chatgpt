# LinkedIn Skills for ChatGPT

**Author: DJ**

A modular LinkedIn skill system adapted for ChatGPT. It uses specialized skills for planning, writing, hooks, auditing, humanization, comments, replies, profile optimization, repurposing, engagement analysis, thread monitoring, and advocacy.

## Operating principle
Route the user's LinkedIn objective to the smallest useful skill, then chain skills when a task crosses multiple stages.

## Default workflow
Plan → Research when needed → Draft → Audit → Humanize → Publish → Engage → Review.
